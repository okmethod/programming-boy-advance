# ゲームルール

このゲームのルール・世界そのものを記述する。  
**このアプリの実装が無くても成立する、普遍的な仕様**だけを置く。

このディレクトリは他のどのドキュメントにも依存しない（[../README.md](../README.md) の「ドキュメント間の依存ルール」を参照）。  
実装への対応（識別子・パス・実装状況）や「どう作るか」は [design/](../design/) 側に置く。

ここで概念に与える名称（和名・英名）は、本プロジェクトのユビキタス言語の正式定義とする（造語を含む）。

# プログラムブロック一覧（コマンド・クエリ・制御）

プレイヤーがオートマトンのプログラムを組むブロックの一覧。  
これらブロック群の正式総称を **プログラムブロック** とする（A面の普段使いは単に「ブロック」でよい）。  
概念の定義は [overview.md](./overview.md)（コマンド／クエリ／プログラム）を正とし、本ファイルは**具体のブロック**を列挙する。

各ブロックは **A面語（JP 名）を正**とし、**EN 識別子を併記**する（命名規約は overview.md に従う）。  
アンロック順＝どの段階で解放されるか（学習曲線）は [design/ux-level-design.md](../design/ux-level-design.md) で規定する。

---

## コマンドブロック

| JP 名    | EN     | 説明                    |
| -------- | ------ | ----------------------- |
| 移動     | move   | 前に 1 マス進む         |
| 向き変え | turn   | 向きを変える            |
| 攻撃     | attack | 正面を攻撃する          |
| 待機     | wait   | 何もせず 1 クロック待つ |

---

## クエリブロック

| JP 名    | EN              | 説明                     |
| -------- | --------------- | ------------------------ |
| 壁クエリ | wall ahead      | 前方に壁があるか         |
| 敵クエリ | enemy ahead     | 敵が前方（近く）にいるか |
| 敵の向き | enemy direction | 敵がどちらを向いているか |

---

## 制御ブロック

| JP 名      | EN         | 説明                                           |
| ---------- | ---------- | ---------------------------------------------- |
| くりかえし | repeat     | 回数または条件で繰り返す                       |
| 条件分岐   | if         | クエリの結果で実行を分岐する                   |
| （順次）   | (sequence) | 上から順に実行する（暗黙＝置くブロックでない） |
